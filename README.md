# My Coffee – Coffee Shop Management Website

## 1. Giới thiệu
My Coffee là dự án website quản lý cửa hàng cà phê được xây dựng trong quá trình học tập, nhằm thực hành phát triển ứng dụng Web với ASP.NET MVC.

## 2. Công nghệ sử dụng
- **Backend:** C#, ASP.NET MVC
- **Frontend:** HTML, CSS, JavaScript, Bootstrap, Razor
- **Database:** SQL Server
- **ORM:** Entity Framework
- **Tools:** Visual Studio, Git, GitHub

## 3. Chức năng chính
- Quản lý sản phẩm.
- Quản lý loại sản phẩm.
- Quản lý khách hàng và nhân viên.
- Quản lý giỏ hàng.
- Quản lý đơn hàng và thanh toán.
- Quản lý tin tức và quảng cáo.

## 4. Cấu trúc dự án
- `Controllers/`: Xử lý yêu cầu và điều hướng chức năng.
- `Models/`: Các lớp dữ liệu và mô hình.
- `Views/`: Giao diện người dùng.
- `Content/`: CSS và tài nguyên giao diện.
- `Scripts/`: JavaScript và thư viện hỗ trợ.
- `Images/`: Hình ảnh sử dụng trong website.

## 5. Cài đặt và chạy dự án
1. Clone repository về máy tính.
2. Mở file `QLMYCF_65130390.sln` bằng Visual Studio.
3. Cấu hình kết nối SQL Server trong file cấu hình ứng dụng.
4. Tạo cơ sở dữ liệu bằng file SQL đi kèm (nếu script đã được chuẩn bị đầy đủ).
5. Khôi phục các package cần thiết.
6. Chạy dự án bằng Visual Studio.

## 6. Mục đích dự án
Dự án giúp thực hành lập trình C#, ASP.NET MVC, thao tác cơ sở dữ liệu SQL Server và xây dựng ứng dụng Web theo mô hình MVC.
